# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v1.16.1

### Improved

- Improved error handling in the update process.

## v1.16.0

### Improved

- Clicking a notification now opens Focus Time.
- Focus Timer is now **Focus Time**.

## v1.15.0

### New

- **Week start config** — Choose Sunday or Monday from Settings → General.

### Improved

- The Entries list is ordered by start time, not by when an Entry was saved.
- General UI and UX improvements across the settings view.

## v1.14.0

### New

- **Pomodoro mode** — Stay using the traditional Pomodoro Technique.

## v1.13.1

## Improved

- Updated the completion sounds list.

## v1.13.0

### New

- **Reset statistics** — Delete every Entry from Settings → General.
- Filter the Entries list by This Week, This Month, or This Year.

### Improved

- General UI and UX improvements across the settings view.

## v1.12.2

### Improved

- General UI and UX improvements across the settings view.

### Fixed

- Midnight split logic from a running timer and from saving an entry.

## v1.12.1

### Improved

- General UI and UX improvements across the app.

## v1.12.0

### New

- **Keyboard shortcuts** — See the full list in Settings → Shortcuts.
- New completion sounds.

### Improved

- Settings is now organized into Tabs.

### Fixed

- Fixed the timer value freezing while tray menu is open.

## v1.11.0

### New

- Dashboard and entries list totals include the active interval.
- The Entries list shows the active interval as a live, non-clickable running card.

### Improved

- A running timer or stopwatch that crosses local midnight is recorded through 23:59:59 and continues as a new interval at 00:00:00, without interrupting the countdown or the stopwatch.

### Fixed

- Fixed keyboard shortcuts not responding the first time a window is opened.

## v1.10.1

### Improved

- Improved feedback when downloading a new app version.
- General UI improvements across the app.

## v1.10.0

### New

- **Save or discard** — Canceling a running timer or stopwatch now asks whether to save the session as an Entry or discard it.

### Improved

- General UI improvements across the app.

## v1.9.0

### New

- **Manual entries** — Add focused time you forgot to start from the Stats Entries tab.
- **Edit and delete sessions** — Change a recorded session's time range or remove it.
- **Keyboard shortcuts** — ⌘1 opens Timer (press again to switch Timer/Stopwatch when idle). ⌘2 opens Stats (press again to switch Dashboard/Entries).

### Improved

- General UI and UX improvements across the app.

## v1.8.0

### New

- **Stats view** — Added a dashboard showing total focused time for the day, week, and month, along with a detailed list of focus sessions.

### Improved

- General UI and UX improvements across the app.

### Fixed

- Fixed an macos 27 issue when left-clicking on the tray icon.

## v1.7.1

## Improved

- Added default preset timer values for fresh install.

## Fixed

- Fixed the progress bar animation and its initial and final states.

## v1.7.0

### Improved

- Improved release notes with better Markdown formatting.
- Improved the app update experience and interface.

### Fixed

- Fixed the timer progress bar position when reopening the window.

## v1.6.1

### Fixed

- Fixed an issue where release notes were not displayed when updating to a new version.
